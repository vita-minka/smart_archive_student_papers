# ThesisHub — живой бенчмарк КТ2

## Быстрый запуск на защите

На macOS откройте Терминал в папке `smart_archive_student_papers-main` и выполните:

```bash
./RUN_KT2.sh
```

Или без shell-скрипта:

```bash
python3 -m benchmark.run --corpus corpus/chunks.jsonl --questions benchmark/questions.jsonl --split all
```

**Python 3 требуется; дополнительные пакеты для запуска готового индекса не нужны.** Результат сохраняется в `benchmark/results.json`.

## Состав пакета

- `corpus/documents/` — 74 оригинальных PDF (сохранены для воспроизводимости).
- `corpus/chunks.jsonl` — 2 260 извлечённых фрагментов, индекс BM25 строится из них при каждом запуске.
- `corpus/manifest.json` и `corpus/document_ids.csv` — соответствие ID документам.
- `benchmark/questions.jsonl` — 20 тематических запросов (10 dev, 10 holdout).
- `benchmark/questions_to_fill.csv` — таблица для исправления релевантности.
- `benchmark/candidate_review.csv` — **важно**: 78 автоматически предложенных пар «вопрос — документ» с фрагментом-подтверждением, в колонке `human_verified` указано `NO`.
- `benchmark/results_provisional.json` — сохранённый результат первого прогона.

## Честная интерпретация

Этот запуск произведён на **реальных PDF**, но метки релевантности пока **НЕ экспертные**: это кандидаты, автоматически отобранные по тематическим словосочетаниям. Поэтому Recall@5 и MRR предварительные и не должны называться финальной экспертной оценкой поиска. Кроме того, отсутствие документа в коротком списке кандидатов не означает нерелевантность: разметка может быть неполной.

Чтобы сделать gold-разметку: откройте `benchmark/candidate_review.csv`, проверьте выдержки и при необходимости исходные PDF. Отметьте релевантные/нерелевантные пары, обновите `gold_document_ids` в `benchmark/questions_to_fill.csv`. У каждого вопроса должно остаться минимум три действительно релевантных документа. Выполните:

```bash
python3 -m benchmark.prepare export
```

После экспорта `benchmark/questions.jsonl` теряет поле предварительного статуса — **делать это следует только после реальной ручной проверки**. Затем заново запустите `./RUN_KT2.sh`.

## Обновить корпус после замены PDF

```bash
python3 -m pip install pymupdf
python3 -m benchmark.prepare import
```

Обратите внимание: если список/имена PDF меняются, ID документов могут поменяться. После обновления корпуса обязательно заново проверьте разметку.
