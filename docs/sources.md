# Источники требований и решений

## Основной источник
**Методические указания к НИРС (ОАД)**, МГТУ им. Н. Э. Баумана, разработчик И. А. Рубинштейн, Москва, 2026, 8 с. Раздел 2, стр. 8: собственный BM25, запрет готовых индексов, тестовый набор с ≥3 релевантными документами на вопрос, метрики и обоснование предобработки. Разделы 1.3–1.5: TF, IDF, BM25, индекс, Recall@k, MRR.

## Образец структуры
Публичный репозиторий `MK-IBM-WWS/CommandWise` (архив, предоставленный для изучения): организация каталогов, SDD-документы, автономный mock-прототип. Его конкретный стек, корпус Linux и готовая библиотека `rank-bm25` **не перенесены**: последняя противоречила бы нашей методичке.

## Исходные сведения о продукте
Тема, описание «Умный архив студенческих работ», сценарий PDF → top-K → LLM и план benchmark (20 вопросов, Recall@5, MRR, время) предоставлены командой проекта.

## Внешние технические решения
FastAPI, PostgreSQL, React и формат API — предварительные проектные решения, а не обязательные требования методички. Их можно пересмотреть после согласования с преподавателем.
