# Проверка комплекта

Проверки относятся только к документации и mock-интерфейсу. Они **не подтверждают** работающий BM25, PDF ingestion, LLM или результаты benchmark.

## Проверить перед публикацией
- Открываются `prototype/auth.html`, `prototype/chat.html`, `prototype/profile.html`.
- Кнопка демонстрационного поиска показывает ответ и источники; окно источника закрывается.
- Выбор PDF не отправляет файл на сервер; статус ясно помечен как mock.
- `benchmark/questions.example.jsonl` — корректный JSONL, но не размеченный gold.
- `spec/tech/api.yaml` и `spec/tech/search-api.yaml` — валидный OpenAPI YAML.
- В Git нет реальных закрытых PDF, паролей, API-ключей и вымышленных benchmark-метрик.

Результаты будущих реальных тестов и Actions записывать только после запуска.
