# Первая контрольная точка — комплект GitHub

## Статус
Подготовлены продуктовые/технические спецификации и автономный HTML/CSS/JS-прототип. Реальная загрузка PDF, поисковый индекс и LLM **ещё не реализованы**.

## Что показать
| Материал | Где находится |
|---|---|
| Тема, аудитория, проблема | `README.md`, `spec/product/product.md` |
| Основной сценарий | `spec/product/scenarios.md`, `docs/demo-script.md` |
| UX и mock | `spec/product/interface.md`, `prototype/chat.html` |
| Архитектура и данные | `spec/tech/architecture.md`, `spec/tech/data-model.md` |
| API-контракты | `spec/tech/api.yaml`, `spec/tech/search-api.yaml` |
| Методика НИРС | `spec/tech/rag.md`, `spec/tech/testing.md` |
| Роли и план | `spec/team.md`, `spec/plan.md` |
| Реальный Git | Создать репозиторий, ветку, commits и PR в GitHub |

В отличие от CommandWise, **в предоставленной методичке НИРС описано итоговое задание, а не отдельные критерии первой точки**. Перечень выше — адаптация формата одногруппника, не дословное требование преподавателя.
