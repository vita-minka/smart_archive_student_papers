# Структура репозитория

| Путь | Назначение |
|---|---|
| `README.md`, `AGENTS.md`, `CONTRIBUTING.md` | Описание и правила работы |
| `spec/product/` | Продукт, интерфейс, сценарии |
| `spec/tech/` | Архитектура, данные, поиск, OpenAPI, проверки, CI/CD |
| `spec/team.md`, `spec/plan.md`, `spec/decisions.md` | Команда, план, решения |
| `docs/` | Точка 1, демонстрация, источники, Git-ветки, проверки |
| `prototype/` | Автономные HTML/CSS/JS-макеты |
| `backend/`, `frontend/`, `search/`, `corpus/`, `benchmark/`, `infra/`, `tests/` | Заготовки будущих компонентов |

На первой точке в большинстве каталогов только README, как в образце CommandWise. Наличие папки не означает реализованный модуль.
