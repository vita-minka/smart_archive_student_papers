# Демонстрация GitHub и прототипа (ориентир 5–7 минут)

1. Открыть README: тема, пользователь, пример «Какие работы были про RAG в 2024?».
2. Показать `spec/product/scenarios.md`: загрузка PDF → поиск → ответ со ссылками.
3. Открыть `prototype/chat.html`: задать вопрос, увидеть mock-ответ, открыть источник, выбрать демонстрационный PDF (без отправки).
4. Показать `spec/tech/architecture.md`: PDF → chunks → собственный BM25 → top-K → LLM.
5. Открыть `spec/tech/rag.md`: запрет готовых индексов и формулу BM25.
6. Показать `benchmark/questions.example.jsonl`: это формат, не размеченный benchmark; объяснить план 20 вопросов и ≥3 gold-документов.
7. Показать роли и план, затем реальные commits/PR, если уже созданы.

**Фраза для защиты:** «Сейчас это проектный комплект и автономный прототип. На следующем этапе мы реализуем собственный BM25 и оценим его на реальном корпусе».
