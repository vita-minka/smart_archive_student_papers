# CI/CD (план)

## Точка 1
Локально проверить структуру, ссылки, синтаксис JSONL и YAML. После публикации можно включить GitHub Actions для проверок документации. Отсутствие workflow не означает, что CI уже работает.

## Следующие этапы
На Pull Request: lint/typecheck, unit BM25, интеграционные API-тесты, проверка безопасности зависимостей. После merge: сборка контейнеров, раздельное хранение секретов, ручное подтверждение деплоя. Benchmark запускать с закреплённой версией корпуса и gold; результаты публиковать без закрытых PDF.
