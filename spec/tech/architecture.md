# Целевая архитектура

**Статус:** описание будущей системы, не реализованное развёртывание.

```text
Браузер / React
       |
       v
FastAPI (доступ, загрузка PDF, запросы, ответы)
   |            |                 |
   v            v                 v
PostgreSQL   PDF storage     Search service (Python)
метаданные                   собственный BM25 + inverted index
   ^                              |
   |                         top-K chunks
   +------------------------------+
                                  |
                            LLM adapter
                                  |
                       ответ + ссылки на страницы
```

## Поток загрузки
Проверка прав/формата → сохранение PDF → извлечение текста с номерами страниц → нормализация и токенизация → фрагментация → построение/обновление обратного индекса.

## Поток вопроса
Проверка доступа и фильтров → одинаковая предобработка запроса → BM25 → top-K → сбор контекста → LLM → проверка ссылок на реальные chunk_id → ответ.

## Отказоустойчивость и безопасность
Лимиты размера PDF, проверка MIME, защита от обхода путей, ACL до поиска, отсутствие ключей в Git. Недоступная LLM не мешает показать найденные фрагменты. Пустой контекст = отказ от неподтверждённого ответа.
