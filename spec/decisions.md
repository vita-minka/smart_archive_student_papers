# Журнал решений

| ID | Решение | Причина / ограничение |
|---|---|---|
| D01 | Собственный BM25 и обратный индекс | Прямое требование методички; готовые индексы запрещены |
| D02 | Единица поиска — фрагмент PDF с document_id и страницей | Проверяемые источники и более точная выдача |
| D03 | Python/FastAPI для API и поиска | Единый стек, удобное извлечение текста |
| D04 | PostgreSQL + файловое хранилище PDF | Метаданные отдельно от файлов; пока проектное решение |
| D05 | LLM только после retrieval | Генерация не заменяет поисковый индекс |
| D06 | Проверка прав и согласия перед публикацией | Студенческие работы могут быть закрыты |
| D07 | Нет автоматического вердикта о плагиате | Тематическое сходство не доказывает заимствование |
| D08 | 20 вопросов, gold ≥3 документа на вопрос | Требование проекта и методички |
