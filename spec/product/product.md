# Спецификация продукта

## Проблема
Студенческие курсовые, дипломы и научные статьи хранятся разрозненно. Студенту трудно узнать, кто уже исследовал похожую тему; преподавателю — найти близкие работы для экспертного анализа. Поиск только по названию недостаточен.

## Цель
Собрать доступный по правам корпус PDF, находить релевантные фрагменты и формировать проверяемые ответы на русском со ссылками на исходные работы.

## Пользователи
- Студент: ищет работы по теме, году, автору, типу документа.
- Преподаватель: сравнивает направления исследований; **не получает автоматический вердикт о плагиате**.

## MVP
1. Загрузка разрешённых PDF и метаданных.
2. Извлечение текста, разбиение на фрагменты с указанием страниц.
3. Поиск собственным BM25 с top-K и фильтрами.
4. Ответ LLM только по найденным источникам, с цитированием.
5. Просмотр первоисточника и сообщение «недостаточно данных».

## Вне MVP
OCR сканов, полноценный антиплагиат, научная экспертиза, автоматическое определение оригинальности, общедоступная индексация закрытых работ, гарантированная проверка истинности выводов.

## Критерии приёмки
Документ доступен в поиске после индексации; выдача воспроизводима при одинаковом индексе; ссылки ведут к существующим документам и страницам; пустая выдача не порождает вымышленных ссылок; benchmark оценивается только по подтверждённому gold.
