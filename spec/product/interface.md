# Интерфейс

## Экраны
- `prototype/auth.html` — демонстрационный вход (без настоящей аутентификации).
- `prototype/chat.html` — вопрос, фильтр по году, пример выдачи, источники, mock-загрузка PDF.
- `prototype/profile.html` — профиль и перечень демонстрационных загрузок.

## Главный экран
Боковая панель: навигация, новый запрос, история. Центральная часть: поле вопроса, фильтр по году, статус поиска, ответ, список источников (название, автор, год, страница), кнопка просмотра подробностей. Отдельная область — выбор PDF и ввод метаданных.

## Состояния
Пустой запрос, ожидание, ответ, нет результатов, ошибка PDF, нет доступа. Мобильная ширина 390 px без горизонтального скролла. Источник показывается в доступном диалоговом окне. Прототип использует только демонстрационные данные и не отправляет файлы на сервер.
